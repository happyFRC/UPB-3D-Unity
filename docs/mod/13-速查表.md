# 13 · 速查表

写模组时把这一页放在旁边，常用的字段、方法、路径都在这里。看不懂的条目回到对应章节看详细说明。

## 文件与文件夹

| 东西 | 位置 | 说明 |
|---|---|---|
| 模组目录 | `<游戏根目录>\Mods\` | 每个子文件夹是一个模组 |
| 主文件 | `Mods\<模组名>\<模组名>.cs` | 必须与文件夹同名，里面要有 `UPBMod` 实现 |
| 描述 | `Mods\<模组名>\desc.json` | `name/author/version/description` |
| 图标 | `Mods\<模组名>\icon.png` | 可选，正方形 |
| 自己的资源 | `Mods\<模组名>\Resource\<命名空间>\...` | 在代码里用 `new Resource(相对路径, 命名空间)` |
| 日志 | `<游戏根目录>\Logs\log-*.txt` | 排查问题先看它 |

## 日志器（`instance.logger`）

| 写法 | 作用 |
|---|---|
| `instance.logger.info("...")` | 普通日志 |
| `instance.logger.warn("...")` | 警告 |
| `instance.logger.err("...")` | 错误（红色） |
| `instance.logger.floatText("...")` | 屏幕左下角黄色浮字 |
| `instance.logger.floatText("...", Color.red)` | 指定颜色浮字 |

## 注册天体

```csharp
SandboxRegister.RegisterPlanet(new PlanetData { ... });       // 行星
SandboxRegister.RegisterDwarfPlanet(new PlanetData { ... });  // 矮行星
SandboxRegister.RegisterMoon(new PlanetData { ... });         // 卫星
SandboxRegister.RegisterStar(new StarData { ... });           // 恒星
```

## 资源引用

```csharp
new Resource("Textures/Planets/Earth_Surface")                 // 游戏内置贴图
new Resource("Textures/planet.png", "MyMod")                    // 自己模组里的贴图
```

- 第二个参数是 `Resource\` 下的文件夹名（命名空间），一般写模组名；
- 覆盖内置：放到 `Mods\<模组名>\Resource\default\<原路径>`。

## 事件

| 事件 | 类型 | 用法 |
|---|---|---|
| `GetBlackbodyColorEvent` | 单播 | `= temperature => (r, g, b);` 返回 0~1 的颜色 |
| `GetLifespanEvent` | 单播 | `= args => 寿命;` 参数 `args.mass`、`args.metallicity`，返回值单位 Myr |
| `BeforeInitSSEEvent` | 列表 | `.Add(() => { ... });` |
| `AfterInitSSEEvent` | 列表 | `.Add(() => { ... });` |
| `OnEvolveStepEvent` | 列表 | `.Add(index => { ...; return EventResult.OK; });` |
| `BeforeApplySSEPointEvent` | 列表 | `.Add(args => { ...; return EventResult.OK; });` |
| `AfterApplySSEPointEvent` | 列表 | `.Add(args => { ... });` |
| `OnInitSpectrum` | 列表 | 进阶，返回 `EventResult` |

- 单播事件赋 `null` 取消；
- 单播事件后设置的覆盖先设置的（多个模组会冲突）；
- 在单播事件里拿默认值：颜色用 `Spectrum.GetBlackbodyColor(t)`，寿命用 `StellarEvolutionEngine.GetLifespan(mass, z)`；
- `EventResult.OK` 表示继续，`EventResult.Skip` 表示跳过/停止（进阶用法，慎用）。

## 常用报错对照

| 提示 | 多半是 |
|---|---|
| 缺少主文件 xxx.cs，已跳过 | 主文件没和文件夹同名，或不在根目录 |
| `CS1002: 应输入 ;` | 少分号 |
| `CS1513: 应输入 }` | 大括号没配对 |
| `CS0103` / `CS0246` | 名字/类型拼错，或缺 `using` |
| `CS0117` / `CS1061` | 字段/方法名写错 |
| 加载后没效果 | 忘了重启、功能在别的场景、或开关没开 |
