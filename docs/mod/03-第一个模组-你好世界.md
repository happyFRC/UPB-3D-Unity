# 03 · 第一个模组：你好世界

这一篇我们从零做一个"什么都不改、只会打招呼"的模组。它的作用是让你确认：**模组能加载、能执行、能看到效果**。做完这个，后面的内容就都是在这个骨架上加东西了。

## 目标

游戏启动后：

1. 模组管理里能看到 `你好世界`，状态是"已加载"；
2. 屏幕左下角出现游戏自己的「模组加载成功！」提示；
3. 日志里出现你写的一句话。

## 第 1 步：新建模组文件夹

在 `Mods` 文件夹里新建一个文件夹，名字叫：

```
HelloWorld
```

> 建议用英文和数字做文件夹名，避免中文路径带来的奇怪问题。

## 第 2 步：新建主文件

在 `HelloWorld` 文件夹里新建一个文件，名字叫：

```
HelloWorld.cs
```

注意：

- 文件名必须和**文件夹同名**（`HelloWorld`），只是扩展名是 `.cs`；
- 不是 `HelloWorld.cs.txt`。如果拿不准，先打开"显示文件扩展名"。

## 第 3 步：写代码

用文本编辑器打开 `HelloWorld.cs`，把下面这些**全部**复制进去，保存：

```csharp
using UnityEngine;

public class HelloWorld : UPBMod {
    public void Startup(UPBModInstance instance) {
        instance.logger.info("你好，模组加载成功！");
    }
}
```

保存时确认编码是 **UTF-8**。

> 想让屏幕上也弹一行自己的字，可以在 `info` 下面加一行 `instance.logger.floatText("Hello World！");`。不过游戏加载完所有模组后也会弹一条「模组加载成功！」，会把它覆盖掉，所以判断有没有加载成功，看日志最可靠。

## 第 4 步：写 desc.json

同一个文件夹里，再新建一个文件，名字叫：

```
desc.json
```

把下面内容复制进去，保存：

```json
{
    "name": "你好世界",
    "author": "你的名字",
    "version": "1.0",
    "description": "我的第一个模组，只会打招呼。"
}
```

这个文件是给"模组管理"面板显示用的。`name` 可以写中文；`author`、`version`、`description` 随便填，但注意：

- 每一行都要用**英文双引号** `"` 包住文字；
- 最后一项后面**不要**多写逗号；
- 文件编码也用 UTF-8。

## 第 5 步：检查文件夹结构

现在应该是这样：

```
Mods\
└─ HelloWorld\
   ├─ HelloWorld.cs
   └─ desc.json
```

## 第 6 步：打开模组并重启游戏

1. 启动游戏，进主菜单；
2. 左侧点「模组管理」；
3. 找到 `你好世界`，点右边显示 `已关闭` 的按钮，变成 `已开启`；
4. 完全退出游戏（不是回主菜单，是关闭程序）；
5. 重新打开游戏。

## 第 7 步：确认效果

三处都确认一下：

1. **模组管理面板**：`你好世界` 那一行显示 `已加载`；
2. **屏幕**：进入主菜单后，屏幕左下角出现「模组加载成功！」的提示；
3. **日志**：打开根目录 `Logs\` 里最新的 `log-...txt`，搜索 `HelloWorld` 或 `你好`，应该能看到类似：

```
[...] [LOG] [你好世界 INFO] 你好，模组加载成功！
```

![开启模组并重启后，左下角会提示加载成功](screenshots/03-hello-world.png)

> 如果模组管理里显示"已关闭"或看不到模组，先回第 6 步检查开关；如果是"加载失败"，看下一篇的排查方法。

## 代码逐行解释（看懂它，后面就不怕了）

```csharp
using UnityEngine;
```

告诉游戏"我要用 Unity 提供的一些东西"。现在用不到，但后面写颜色、数学时会用到，先留着。

```csharp
public class HelloWorld : UPBMod {
```

定义一个"类"，名字叫 `HelloWorld`。`: UPBMod` 表示这个类是一个模组入口，游戏会认它。

```csharp
    public void Startup(UPBModInstance instance) {
```

模组的"启动方法"。游戏加载你的模组时，会调用这个方法一次。`instance` 是游戏给你的"工具包"，里面有日志器（`logger`）和模组信息（`entry`）。

```csharp
        instance.logger.info("你好，模组加载成功！");
```

往日志里写一行普通信息。


```csharp
    }
}
```

结束方法和类。**大括号必须成对**：`{` 和 `}` 数量要一样。

## 小练习

改一改这几处，保存后重启游戏，看看变化：

- 在 `info` 下面加一行 `instance.logger.floatText("Hello World！");`，重启后看屏幕左下角（注意它可能被「模组加载成功！」覆盖）；
- 把 `instance.logger.info(...)` 换成 `instance.logger.warn(...)`，看日志里变成警告；
- 在 `Startup` 里加第二行 `instance.logger.info("第二行日志");`。
