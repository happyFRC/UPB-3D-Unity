# 12 · 常见问题 FAQ

这里收集了新手最常遇到的问题。遇到问题先按这里排查，还不行再看 [05-日志与出错排查](05-日志与出错排查.md)。

## 1. 模组管理里根本看不到我的模组

- 文件夹是不是直接放在 `Mods\` 下？（`Mods\HelloWorld\`，不是 `Mods\新建文件夹\HelloWorld\`）
- 主文件是不是 `文件夹名.cs`，且就在模组文件夹根目录？
- 扩展名是不是变成了 `.cs.txt`？
- 改完有没有重启游戏？

## 2. 显示"加载失败"，后面有一句英文

这是代码编译错误。打开 `Logs\` 里最新的日志，搜索 `编译失败`，会看到 `文件(行,列): error CSxxxx: 说明`。按行号和说明改代码（常见原因见 [05 篇](05-日志与出错排查.md) 的表格）。

## 3. 显示"已加载"，但游戏里看不到效果

- 你的功能是不是在别的场景才出现？（比如注册行星只在沙盒的创建面板里）
- 模组面板里状态是不是"已加载"？
- 在 `Startup` 里加一行 `instance.logger.info("测试");`，重启后看日志里有没有——没有说明代码没执行到。
- 是不是忘了重启游戏？（改代码后必须重启）

## 4. 我改了代码，但游戏没变化

模组在**游戏启动时**编译，改完要**完全退出游戏再打开**，不是回主菜单。

## 5. 行星/恒星/贴图不显示

- 检查日志里有没有 `[Resource] ... 找不到` 之类的警告；
- 检查 `new Resource("...", "命名空间")` 的路径和实际文件位置是否一致（大小写也要一致）；
- 检查文件是不是真的在 `Resource\<命名空间>\` 下面；
- 确认文件是 `.png` 或 `.jpg`，不是 `.psd`。

## 6. 行星变成白球或黑球

通常是贴图没读到，游戏回退到了默认外观。按上一条检查路径；也可以先换成内置贴图确认代码没问题：

```csharp
surface = new Resource("Textures/Planets/Earth_Surface"),
```

## 7. 中文变成乱码

保存文件时编码没选 UTF-8。用编辑器重新"另存为"，编码选 **UTF-8**（不要 UTF-16、不要 ANSI）。

## 8. 游戏报红字/卡死/闪退

- 先退出游戏，在模组管理里把可疑模组**关掉**，重启确认恢复正常；
- 再单独打开它，看日志里第一个红色错误是哪一行；
- 事件里写了复杂逻辑、或者修改了传入的数据，最容易出问题，先简化再试。

## 9. 两个模组冲突怎么办

- 面板里如果有"加载失败"，先按错误改；
- 两个模组都改同一个单播事件（比如恒星颜色）时，只有后加载的生效——这是设计如此，不是 bug；
- 两个模组文件夹同名时，内置优先，外部会被跳过；改个名字即可。

## 10. 装模组会影响存档吗

- 模组主要在启动时注册内容，一般不会破坏已有存档；
- 但**删掉一个模组后，存档里用到它的天体可能变成默认样子或消失**，所以装/卸模组前建议备份存档；
- 存档位置在系统的用户数据目录（`AppData\LocalLow\...`），不在游戏目录里。

## 11. 怎么关闭或删除模组

- 关闭：模组管理 → 点"已开启"变"已关闭" → 重启；
- 删除：关闭游戏，删掉 `Mods\` 里对应的文件夹。

## 12. 日志在哪里

游戏根目录的 `Logs\` 文件夹，最新的 `log-日期-时间.txt`。

## 13. 需要安装 Unity 或编程软件吗

不需要。模组就是文本文件，任何文本编辑器都能写，游戏启动时自己编译。

## 14. 能做"内置模组"吗

普通玩家不需要。内置模组是随游戏一起发布的，放在游戏的 `StreamingAssets\Mods` 里；你自己玩只要放 `Mods\` 就行。

## 15. 我的模组能发到群里吗

可以。打包方法、命名和注意事项见 [11-发布与分享](11-发布与分享.md)。发之前最好自己完整测一遍：开启、重启、进相关场景确认。

如果这里没有你的问题，把日志里和你模组相关的那几行（连同错误编号）发到 QQ 群，方便大家帮你定位。
