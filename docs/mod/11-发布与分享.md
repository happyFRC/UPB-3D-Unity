# 11 · 发布与分享

做完模组，你可能会想发给朋友，或者发到 QQ 群里。这一篇讲怎么打包、命名、安装，以及要注意什么。

## 打包：只压缩"模组文件夹"

假设你的模组叫 `PlanetPack`，目录是：

```
Mods\
└─ PlanetPack\
   ├─ PlanetPack.cs
   ├─ desc.json
   └─ Resource\...
```

正确做法：**右键 `PlanetPack` 这个文件夹 → 压缩成 zip**。

得到 `PlanetPack.zip`，里面打开应该是：

```
PlanetPack\
├─ PlanetPack.cs
├─ desc.json
└─ Resource\...
```

**不要**把整个 `Mods` 文件夹压进去，也不要带游戏本体、存档、日志。

## 命名建议

```
模组名-v版本号.zip
```

例如：

```
PlanetPack-v1.0.zip
```

版本号和你 `desc.json` 里的 `version` 保持一致，别人一看就知道是不是新版。

## 别人怎么安装

1. 解压压缩包；
2. 把里面的 `PlanetPack` 文件夹整个放进自己的 `Mods\` 目录（路径变成 `Mods\PlanetPack\`）；
3. 启动游戏 → 模组管理 → 开启 → 重启。

可以提醒对方：**模组默认关闭，必须手动开启再重启**。

## 更新版本

1. 改好代码，把 `desc.json` 里的 `version` 改成 `1.1`；
2. 重新压缩成 `PlanetPack-v1.1.zip`；
3. 提醒别人：先删掉旧的 `Mods\PlanetPack` 文件夹，再放新的（直接覆盖有时会残留旧文件）。

## 写一段清楚的介绍

发模组时最好带上：

- 模组名字、版本、作者；
- 它能做什么（一两句话）；
- 需不需要重新开档；
- 已知问题；
- 一张截图（有图更容易被安装）。

## 注意：模组是"会运行的程序"

模组里的 `.cs` 会被游戏编译并执行，能力很大。所以：

- **只安装你信任来源的模组**；
- 发模组时不要夹带可执行文件（`.exe`、`.dll` 之类），别人也不敢装；
- 用了别人的图片、字体、音乐，要确认允许使用，最好在介绍里注明来源。

## 和内置模组的区别

你会在面板里看到两种标签：

| 标签 | 来源 | 说明 |
|---|---|---|
| `外部` | `Mods\` 目录 | 玩家自己安装的模组，你就是做这种 |
| `内置` | 游戏自带的模组 | 随游戏发布，不需要你操作 |

两个模组**文件夹同名**时，内置的优先，外部那个会被跳过。所以起名尽量独特一点。

## 删除模组

关闭游戏，直接把 `Mods\` 里对应的文件夹删掉，再启动游戏即可。
