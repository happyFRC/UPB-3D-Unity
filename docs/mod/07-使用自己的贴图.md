# 07 · 使用自己的贴图

上一篇我们借用了游戏内置的地球贴图。这一篇教你把自己画的图片用到行星上。

## 先理解"资源引用"

代码里写贴图时用的是这样一行：

```csharp
surface = new Resource("Textures/planet.png", "MyPlanet")
```

它有两个参数：

| 参数 | 含义 |
|---|---|
| 第一个 `"Textures/planet.png"` | 相对路径（从下面说的"资源文件夹"开始算） |
| 第二个 `"MyPlanet"` | 命名空间，对应模组里的 `Resource\MyPlanet\` 文件夹；一般写模组名 |

如果不写第二个参数：

```csharp
surface = new Resource("Textures/Planets/Earth_Surface")
```

那就是引用**游戏内置**的贴图。

## 贴图放在哪

假设模组文件夹叫 `MyPlanet`，贴图文件叫 `planet.png`，那么完整结构是：

```
Mods\
└─ MyPlanet\
   ├─ MyPlanet.cs
   ├─ desc.json
   └─ Resource\
      └─ MyPlanet\
         └─ Textures\
            └─ planet.png
```

对应代码：

```csharp
surface = new Resource("Textures/planet.png", "MyPlanet")
```

规则很简单：**`Resource\<命名空间>\` 后面的路径，就是 `new Resource(...)` 的第一个参数**。

## 完整例子

模组文件夹 `MyPlanet`：

```
MyPlanet\
├─ MyPlanet.cs
├─ desc.json
└─ Resource\
   └─ MyPlanet\
      └─ Textures\
         └─ planet.png
```

`MyPlanet.cs`：

```csharp
using UnityEngine;

public class MyPlanet : UPBMod {
    public void Startup(UPBModInstance instance) {
        SandboxRegister.RegisterPlanet(new PlanetData {
            name = "我的行星",
            mass = 1.0,
            radius = 1.0,
            temperature = 288.0,
            rotationPeriodDays = 1.0,
            surface = new Resource("Textures/planet.png", "MyPlanet"),
        });

        instance.logger.info("已注册：我的行星");
    }
}
```

## 图片有什么要求

- 格式：`.png` 或 `.jpg`；
- 形状：行星贴图用**长宽 2:1 的全景图**（等距圆柱投影），比如 1024×512、2048×1024；
- 大小：建议单张不超过几 MB，太大的图会拖慢加载；
- 颜色：普通图片即可，不需要特殊格式。

## 覆盖游戏自带的贴图

如果你想让**所有**用到某张内置贴图的地方都换成自己的图，可以放到 `default` 命名空间：

```
Mods\
└─ MyMod\
   └─ Resource\
      └─ default\
         └─ Textures\
            └─ Planets\
               └─ Earth_Surface.png
```

这样游戏原本的 `Textures/Planets/Earth_Surface` 就会被你的图覆盖。

## 贴图不显示怎么办

1. 检查路径大小写：`Textures` 是大写 T，文件名要完全一致；
2. 检查文件是不是真的在 `Resource\<命名空间>\` 下面；
3. 看日志里有没有 `[Resource] ... 找不到贴图 ...` 之类的警告；
4. 确认代码里的第二个参数和文件夹名一致（比如都叫 `MyPlanet`）；
5. 确认游戏已重启。

如果行星是纯白或纯黑，通常是路径不对、图片没读到，游戏回退到了默认颜色。
