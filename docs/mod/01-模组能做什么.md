# 01 · 模组能做什么

## 先说人话：模组是什么？

模组（Mod）就是**一个文件夹**。你把这个文件夹放进游戏的 `Mods` 目录，游戏启动时会读取里面的文字和图片，然后让它们生效。

这个文件夹里最重要的东西是几个 `.cs` 文件（读作"C sharp 文件"）。它们其实是**纯文本文件**，里面写的是给游戏看的"指令"。游戏启动时会把这些文字翻译成程序（这个过程叫"编译"），然后执行。

所以你不需要安装任何编程软件，用记事本、VS Code 之类的文本编辑器就能写模组。

## 模组可以做什么？

在《行星球宇宙》里，模组目前可以做这些事：

- **往沙盒里加天体**：加行星、矮行星、卫星，甚至"彩蛋"天体；
- **加恒星**：给沙盒的恒星选择列表加一颗自己的恒星；
- **换贴图**：给自己的天体用你自己画的图片，或者覆盖游戏自带的贴图；
- **改事件**：比如把所有恒星的颜色改成别的颜色、改恒星寿命、在演化每一步做点什么；
- **加日志和提示**：在日志里打印信息，或者在屏幕上弹一行字，方便你确认模组有没有生效。

## 模组不能做什么？

- 不能改游戏本体的文件（也不建议改，更新游戏时会被覆盖）；
- 不能保证永远兼容——游戏更新后，模组里用到的接口可能会变；
- 不能替别人操作联机内容（本作没有联机）。

## 模组是怎么被加载的？

简单说：

1. 游戏启动，扫描 `Mods` 文件夹里的每个子文件夹；
2. 每个子文件夹被当成一个模组，游戏会编译里面所有 `.cs` 文件；
3. 编译成功后，游戏找到"主文件"里实现了 `UPBMod` 的那个类，创建一个实例，调用它的 `Startup` 方法；
4. 你在 `Startup` 里写的事情（比如注册行星、设置事件）就生效了。

所以**模组的效果基本都在游戏启动时完成**。改完模组文件后，需要**退出游戏再重新打开**才会生效。

## 重要提醒

- 模组是"会运行的程序"，只安装你信任的来源提供的模组；
- 写错代码一般不会弄坏游戏，但可能让某个模组加载失败（面板里会显示"加载失败"），或者让游戏报错。建议先在测试存档里试；
- 所有模组默认是**关闭**的，需要在"模组管理"里打开并重启才生效——这是为了防止别人发来的模组在你不知情的情况下运行。
