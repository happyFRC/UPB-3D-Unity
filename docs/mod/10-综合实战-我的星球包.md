# 10 · 综合实战：我的星球包

这一篇把前面的知识拼起来，做一个完整的模组：**两颗行星 + 一张自己的贴图 + 一段事件效果**。

做完这一个，你就已经会写大部分常见模组了。

## 目标

- 沙盒创建面板里多两颗行星："海蓝星"和"赤砂星"；
- "海蓝星"用你自己放的贴图；
- 所有恒星的颜色稍微偏暖（事件效果）；
- 模组管理面板显示正确的名字、作者、版本、说明和图标。

## 第 1 步：建文件夹

```
Mods\
└─ PlanetPack\
   ├─ PlanetPack.cs
   ├─ desc.json
   ├─ icon.png
   └─ Resource\
      └─ PlanetPack\
         └─ Textures\
            └─ ocean.png
```

- `ocean.png`：你自己准备一张 2:1 的全景图（没有的话，先随便找一张图片改名也可以，颜色会怪一点，但能验证流程）；
- `icon.png`：可选，128×128 左右的正方形图标。

## 第 2 步：desc.json

    "author": "你的名字",

    "description": "新增海蓝星、赤砂星，并让恒星颜色偏暖。"

## 第 3 步：主文件

`PlanetPack.cs`：

```csharp
using UnityEngine;

public class PlanetPack : UPBMod {
    public void Startup(UPBModInstance instance) {
        // 行星 1：用自己的贴图
        SandboxRegister.RegisterPlanet(new PlanetData {
            name = "海蓝星",
            mass = 1.2,
            radius = 1.1,
            temperature = 292.0,
            rotationPeriodDays = 0.9,
            surface = new Resource("Textures/ocean.png", "PlanetPack"),
            atmosphere = new Resource("Textures/Planets/Earth_Atmosphere"),
            atmosphereShell = true,
        });

        // 行星 2：借用内置贴图
        SandboxRegister.RegisterPlanet(new PlanetData {
            name = "赤砂星",
            mass = 0.4,
            radius = 0.7,
            temperature = 320.0,
            rotationPeriodDays = 2.0,
            surface = new Resource("Textures/Planets/Mars"),
        });

        // 事件：恒星颜色偏暖
        UPBEventBus.GetBlackbodyColorEvent = temperature => {
            var c = Spectrum.GetBlackbodyColor(temperature);
            return (c.r * 1.05f, c.g * 0.98f, c.b * 0.9f);
        };

        instance.logger.info("星球包加载完成：海蓝星、赤砂星");
    }
}
```

- [ ] 所有文件 UTF-8 编码。

## 第 5 步：启用并验证

1. 启动游戏 → 模组管理 → 开启「我的星球包」→ 重启；
2. 面板应该显示：名字、作者、版本、说明、图标，状态"已加载"；
3. 进入沙盒 → 创建行星列表：能看到"海蓝星"和"赤砂星"；
4. 放一颗"海蓝星"，看贴图是不是你放的那张；
5. 进入恒星演化，看恒星颜色是不是偏暖；
6. 日志里搜索 `星球包加载完成`。

## 常见坑

- **贴图没显示**：检查 `Resource\PlanetPack\Textures\ocean.png` 的路径和 `new Resource("Textures/ocean.png", "PlanetPack")` 是否完全对应；
- **面板显示"加载失败"**：看日志里的 `error CSxxxx`，多半是少分号、括号不配对、或者字段名拼错；
- **颜色没变化**：确认是"恒星演化"场景（不是沙盒），并且模组状态是"已加载"；
- **改了没反应**：记得每次都要**重启游戏**。
