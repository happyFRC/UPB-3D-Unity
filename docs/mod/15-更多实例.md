# 15 · 更多实例

这一篇是"照着自己做"的实例合集。每个例子都是完整可运行的主文件内容，复制到 `Mods\<名字>\<名字>.cs`，配一个 `desc.json`，开启、重启就能看到效果。

## 实例 1：一次加三颗行星（数组 + foreach）

**新建模组**：文件夹 `ThreePlanets`，主文件 `ThreePlanets.cs`。

```csharp
using UnityEngine;

public class ThreePlanets : UPBMod {
    public void Startup(UPBModInstance instance) {
        PlanetData[] planets = {
            new PlanetData {
                name = "小蓝",
                mass = 1.0, radius = 1.0, temperature = 288.0,
                surface = new Resource("Textures/Planets/Earth_Surface"),
            },
            new PlanetData {
                name = "小红",
                mass = 0.5, radius = 0.7, temperature = 320.0,
                surface = new Resource("Textures/Planets/Mars"),
            },
            new PlanetData {
                name = "小黄",
                mass = 2.0, radius = 3.0, temperature = 500.0,
                surface = new Resource("Textures/Planets/Jupiter"),
            },
        };

        foreach (PlanetData p in planets) {
            SandboxRegister.RegisterPlanet(p);
        }

        instance.logger.info("已注册 " + planets.Length + " 颗行星");
    }
}
```

**你会学到**：

- `PlanetData[]` 是"行星数据数组"；
- `foreach` 把数组里的每一颗依次拿出来；
- `planets.Length` 是数量。

**看到什么**：沙盒创建行星的列表里出现三颗新行星。

**易错点**：数组里每一项之间用**逗号**，最后一项后面也可以有逗号，但 `}` 后面不要多写逗号。

## 实例 2：随机生成 5 颗行星（for + Random）

**新建模组**：文件夹 `RandomPlanets`，主文件 `RandomPlanets.cs`。

```csharp
using UnityEngine;

public class RandomPlanets : UPBMod {
    public void Startup(UPBModInstance instance) {
        for (int i = 1; i <= 5; i++) {
            SandboxRegister.RegisterPlanet(new PlanetData {
                name = "随机星球 " + i,
                mass = UnityEngine.Random.Range(0.2f, 3f),
                radius = UnityEngine.Random.Range(0.3f, 2f),
                temperature = UnityEngine.Random.Range(200f, 1200f),
                surface = new Resource("Textures/Planets/Mars"),
            });
        }

        instance.logger.info("已随机生成 5 颗行星");
    }
}
```

**你会学到**：

- `for (int i = 1; i <= 5; i++)` 重复 5 次；
- `UnityEngine.Random.Range(最小, 最大)` 生成随机小数；
- `"随机星球 " + i` 把数字拼到名字后面。

**看到什么**：每次重启游戏，列表里 5 颗行星的参数都不一样。

**易错点**：`Random` 前面写了 `UnityEngine.`，是为了和系统自带的 `Random` 区分；不要删掉。

## 实例 3：按温度给恒星调色（事件 + if / else）

**新建模组**：文件夹 `TemperatureTint`，主文件 `TemperatureTint.cs`。

```csharp
using UnityEngine;

public class TemperatureTint : UPBMod {
    public void Startup(UPBModInstance instance) {
        UPBEventBus.GetBlackbodyColorEvent = temperature => {
            var c = Spectrum.GetBlackbodyColor(temperature);

            if (temperature < 3500.0) {
                return (c.r, c.g * 0.8f, c.b * 0.6f);      // 冷星偏橙
            }
            if (temperature > 10000.0) {
                return (c.r * 0.9f, c.g * 0.95f, c.b * 1.2f); // 热星偏蓝
            }
            return c;                                       // 其他保持默认
        };
    }
}
```

**你会学到**：

- 在事件里用 `if` 判断当前温度；
- `Spectrum.GetBlackbodyColor(temperature)` 拿默认颜色；
- `return c;` 表示"不改"。

**看到什么**：恒星演化/沙盒里，偏冷的恒星更橙，偏热的更蓝。

**易错点**：`c.b * 1.2f` 可能超过 1，一般问题不大；想稳妥可以用 `UnityEngine.Mathf.Clamp01(...)` 包一下。

## 实例 4：给行星加大气和特殊自转

**新建模组**：文件夹 `TiltedPlanet`，主文件 `TiltedPlanet.cs`。

```csharp
using UnityEngine;

public class TiltedPlanet : UPBMod {
    public void Startup(UPBModInstance instance) {
        SandboxRegister.RegisterPlanet(new PlanetData {
            name = "倾斜星",
            mass = 1.0,
            radius = 1.0,
            temperature = 280.0,
            rotationPeriodDays = 0.5,     // 半天转一圈
            rotationDirection = -1,       // 逆向自转
            axialTiltDeg = 45.0,          // 轴倾角 45 度
            atmosphereMass = 1.0,         // 一个地球大气
            greenhouseFactor = 0.3,       // 温室效应
            surface = new Resource("Textures/Planets/Earth_Surface"),
            atmosphere = new Resource("Textures/Planets/Earth_Atmosphere"),
            atmosphereShell = true,
            atmosphereColorR = 0.8f,
            atmosphereColorG = 0.4f,
            atmosphereColorB = 0.2f,
            trailColorR = 1.0f,
            trailColorG = 0.6f,
            trailColorB = 0.2f,
        });

        instance.logger.info("已注册：倾斜星");
    }
}
```

**你会学到**：

- 一个对象初始化器里可以写很多字段；
- 颜色是三个 0~1 的小数（红、绿、蓝）。

**看到什么**：沙盒里放上去的行星自转方向相反、有橙色大气和橙色轨迹。

## 实例 5：覆盖游戏自带的贴图（不需要写代码）

这个实例只放文件，不改代码。

```
Mods\
└─ MyTextureOverride\
   ├─ MyTextureOverride.cs      ← 只打一行日志即可
   └─ Resource\
      └─ default\
         └─ Textures\
            └─ Planets\
               └─ Earth_Surface.png
```

主文件随便写：

```csharp
public class MyTextureOverride : UPBMod {
    public void Startup(UPBModInstance instance) {
        instance.logger.info("自定义地球贴图已生效");
    }
}
```

**你会学到**：`Resource\default\` 目录会**覆盖**游戏内置的同名贴图。

**看到什么**：所有用 `Textures/Planets/Earth_Surface` 的地方（包括内置地球）都换成你的图。

**易错点**：路径和文件名必须和内置的完全一致（大小写也要一致）。

## 实例 6：监听演化过程（列表事件）

**新建模组**：文件夹 `EvolutionWatcher`，主文件 `EvolutionWatcher.cs`。

```csharp
using UnityEngine;

public class EvolutionWatcher : UPBMod {
    public void Startup(UPBModInstance instance) {
        UPBEventBus.AfterApplySSEPointEvent.Add(args => {
            if (args.sseIndex % 100 != 0) return;   // 每 100 步才记录一次
            instance.logger.info("第 " + args.sseIndex + " 步，年龄 " + args.point.time.ToString("F0") + " 年");
        });
    }
}
```

**你会学到**：

- 列表事件用 `.Add(...)` 添加；
- `args.sseIndex` 是第几步；
- `args.point.time` 是这一步的年龄；
- `% 100 != 0` 表示"不是 100 的倍数就跳过"，避免刷屏。

**看到什么**：恒星演化时，日志里每隔 100 步出现一条记录。

**易错点**：不要每步都打日志，会明显拖慢游戏。

## 实例 7：两个模组同时改颜色会怎样

同一个单播事件，后设置的会覆盖先设置的。你可以自己验证：

1. 做两个模组，都设置 `UPBEventBus.GetBlackbodyColorEvent`，一个绿色、一个红色；
2. 都开启，重启；
3. 结果只会有一种颜色（后加载的那个）。

这是设计如此。要"叠加"效果，只能在一个模组里把逻辑写在一起。

## 实例 8：把前面的东西组合起来

一个真实模组通常是这样的结构：

```
Mods\
└─ MyPack\
   ├─ MyPack.cs
   ├─ desc.json
   ├─ icon.png
   └─ Resource\
      └─ MyPack\
         └─ Textures\
            ├─ a.png
            └─ b.png
```

`MyPack.cs` 里可以同时做：

- 注册几颗行星（实例 1、2）；
- 设置事件（实例 3）；
- 打日志（所有例子）；
- 用自定义贴图（[07](07-使用自己的贴图.md)）。

把它们放进同一个 `Startup` 里就行，没有数量限制。

## 常见错误速查

| 现象 | 原因 |
|---|---|
| 行星列表里没有新行星 | 模组没开启 / 没重启 / 注册代码没执行（看日志） |
| 名字重复不好区分 | 换个独特名字 |
| 颜色没变化 | 事件只对恒星生效；确认在演化场景看 |
| 贴图是白球 | 路径或文件名不对 |
| 报错 `CS0103` | 名字拼错，注意大小写 |
| 报错 `CS0117` | 字段名写错（对照 [13 速查表](13-速查表.md)） |
| 游戏卡 | 事件里写了太重的逻辑，先删掉再试 |
