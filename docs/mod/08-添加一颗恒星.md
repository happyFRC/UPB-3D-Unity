# 08 · 添加一颗恒星

上一篇加了行星，这一篇给沙盒"选择恒星"的列表里加一颗自己的恒星。

## 目标

沙盒里选择/创建恒星时，列表里多出一颗"我的恒星"。

## 新建模组

```
Mods\
└─ MyStar\
   ├─ MyStar.cs
   └─ desc.json
```

`desc.json`：

```json
{
    "name": "我的恒星",
    "author": "你的名字",
    "version": "1.0",
    "description": "添加一颗自定义恒星。"
}
```

`MyStar.cs`：

```csharp
using UnityEngine;

public class MyStar : UPBMod {
    public void Startup(UPBModInstance instance) {
        SandboxRegister.RegisterStar(new StarData {
            name = "我的恒星",
            mass = 1.0,
            metallicity = 0.02,
            age = 4600.0,
            temp_review = 5772.0,
            rotationPeriodDays = 25.38,
        });

        instance.logger.info("已注册恒星：我的恒星");
    }
}
```

保存 → 模组管理里开启 → 重启游戏 → 进沙盒 → 选择恒星，列表里就能看到它。

## 参数说明

`StarData` 的字段：

| 字段 | 含义 | 单位/取值 | 参考值（太阳） |
|---|---|---|---|
| `name` | 恒星名字 | 文字 | `"太阳"` |
| `mass` | 质量 | 太阳质量 | `1.0` |
| `metallicity` | 金属度 Z | 小数 | `0.02` |
| `age` | 年龄 | 百万年（Myr） | `4600`（46 亿年） |
| `temp_review` | 表面温度 | 开尔文（K） | `5772` |
| `rotationPeriodDays` | 自转周期 | 天 | `25.38` |

说明：

- 恒星的半径、光度、光谱型这些不用你填，游戏会根据质量、金属度、年龄用恒星演化模型算出来；
- `temp_review` 是注册时带的一个参考温度，游戏启动时会用模型算出的结果校正；
- 质量太大/太小会被限制在游戏允许的范围内。

## 试试不同质量

复制一份代码，改几个值就能做出不同恒星：

| 想做的 | mass | metallicity | age |
|---|---|---|---|
| 红矮星 | `0.3` | `0.02` | `10000` |
| 蓝巨星 | `10.0` | `0.02` | `10` |
| 老年恒星 | `1.0` | `0.02` | `11000` |

改完记得重启游戏再进沙盒看效果。

## 常见问题

- **列表里没有**：确认开关、重启、日志里有 `已注册恒星：我的恒星`；
- **名字重复**：换一个不冲突的名字；
- **数值看起来奇怪**：检查是不是把 `age` 当成"年"写了（它单位是**百万年**，4600 表示 46 亿年）。
